## Ver en local

Abrí `index.html` en el navegador, o serví la carpeta:

```bash
cd acacia-web
python3 -m http.server 8080
```

Luego visitá `http://localhost:8080`.

## Diseño

Paleta inspirada en el logo Acacia (negro carbón + ámbar/dorado). El inicio es tipográfico y geométrico, sin fotos de propiedades.
